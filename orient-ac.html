Detailed Error Code Guide

Error Code E1

Indoor Unit Communication / PCB Error

Meaning: Communication problem within the indoor unit or PCB failure.

Solutions: Turn off power at the circuit breaker for 15 minutes for a complete reset. Check all wiring connections inside the indoor unit. Inspect connectors between the main PCB and display board. Look for burnt components or swollen capacitors on the PCB. If there is visible damage, the PCB may need replacement. If wiring is good and there is no visible damage but the error continues, call a technician.

Error Code E2

Room Temperature Sensor Error

Meaning: The sensor that measures room temperature has failed or is sending incorrect signals.

Solutions: Turn off power. Open the front panel and locate the room temperature sensor near the air intake. Clean the sensor gently with a soft cloth. Measure sensor resistance with a multimeter at room temperature. Normal resistance is 5 to 10 kilo-ohms at 25 degrees. If resistance is infinite or zero, replace the sensor.

Error Code E3

Evaporator Coil Temperature Sensor Error

Meaning: The sensor monitoring the evaporator coil temperature has failed.

Solutions: Disconnect power. Locate the evaporator sensor clipped to the evaporator coil. Check connections and measure resistance. Replace the sensor if it is faulty.

Error Code E4

Outdoor Unit Error

Meaning: Problem with the outdoor unit. This could be a sensor, communication issue, or PCB problem.

Solutions: Turn off power to both indoor and outdoor units. Clean the outdoor condenser coil thoroughly with a water hose. Remove any debris or obstructions around the outdoor unit. Check the wiring connections between the indoor and outdoor units. If the problem continues, the outdoor sensor or PCB may need inspection.

Error Code E5

Compressor Error / Overload Protection

Meaning: The compressor is not running properly or the overload protection has tripped.

Solutions: Turn off the AC and let the compressor cool for 30 to 60 minutes. Clean the outdoor condenser coil thoroughly. For non inverter models, check the compressor capacitor. Ensure the outdoor fan is running properly. If the compressor is hot but not running, the overload may be tripped. Wait for it to reset. If the compressor clicks but will not start, the capacitor is likely bad. Compressor repair requires specialized knowledge. Call a certified technician.

Error Code E6

Indoor Fan Motor Error

Meaning: The indoor fan motor is not running properly.

Solutions: Turn off power and remove the front panel. Check if the fan rotates freely with no obstruction. Clean the fan blades. Check the fan capacitor with a multimeter. Replace it if faulty. If the capacitor is good, the motor may need replacement.

Error Code E7

Outdoor Fan Motor Error

Meaning: The outdoor fan motor is not running properly.

Solutions: Turn off power to the outdoor unit. Remove any debris or obstructions. Check if the fan rotates freely. Test the fan capacitor with a multimeter. Replace it if faulty. If the capacitor is good, the motor may need replacement.

Error Code E8

EEPROM Error (Main Board Memory)

Meaning: The main control board memory chip has failed.

Solutions: Try a power reset. Turn off the circuit breaker for 15 minutes. If the error continues, the main PCB needs replacement. Contact an Orient service center.

Error Code E9

High Pressure Protection

Meaning: The system pressure has exceeded safe limits.

Solutions: Turn off the AC and let the pressure equalize for 30 minutes. Thoroughly clean the outdoor condenser coil. Ensure the outdoor fan is running properly. Remove any obstructions around the outdoor unit. If the problem continues, call a technician for a refrigerant check.

Frequently Asked Questions

What does E1 mean on Orient AC?
E1 indicates an indoor unit communication or PCB error. Try resetting by turning off power for 15 minutes. Check the wiring connections. If the problem continues, the PCB may need replacement.
How do I reset my Orient AC?
Turn off the AC from the remote. Then switch off the circuit breaker for 10 to 15 minutes. Turn the breaker back on, then turn on the AC. This clears temporary errors after power fluctuations.
Why does my Orient AC show E4?
E4 indicates an outdoor unit error. Clean the outdoor condenser coil, check for obstructions, and ensure the outdoor fan is running. If the problem continues, the sensor or PCB may need inspection.
Is Orient AC good for Pakistan?
Yes, Orient ACs are designed specifically for Pakistani conditions. They handle high temperatures well and have good after sales service throughout Pakistan.
How often should I service my Orient AC?
Service twice per year. Once before summer in February or March, and once before winter in October or November. Clean filters monthly during summer. In dusty areas like Karachi, clean the outdoor unit every 3 months.
What does E5 mean on Orient AC?
E5 is a compressor error. Let the unit cool, clean the outdoor unit, and check if the outdoor fan is running. If the problem continues, call a technician for compressor diagnosis.

Pakistan Specific Tips: Install a voltage stabilizer to protect the PCB from power fluctuations. Clean filters every 2 weeks in dusty areas. Check for animal damage to wiring, which is common in many areas. In extreme heat above 45 degrees, it is normal for ACs to run continuously. For professional service, use authorized Orient service centers.

Safety Warning: Always disconnect power before any inspection. For compressor, refrigerant, or PCB issues, always call certified technicians. Electrical components can be dangerous.

Detailed Error Code Guide

Error Code E1

Indoor PCB Communication Error / Indoor Fan Motor Problem

Symptoms: Indoor fan not running, or AC not responding to remote.

Common causes: Loose wiring, fan motor seized, capacitor failure, PCB issue.

Solutions:

  • Turn off power and check if indoor fan spins freely
  • Inspect all wiring connections
  • Test fan motor capacitor with multimeter
  • If capacitor is bulging or leaking, replace it
  • If fan motor does not run with proper voltage, motor needs replacement

Error Code E2

Room Temperature Sensor Error / Freeze Protection

Symptoms: AC runs but does not cool, ice on indoor unit, water leakage.

Common causes: Dirty air filters, faulty sensor, loose wiring.

Solutions:

  • Clean air filters thoroughly
  • Turn off AC and let ice thaw for 2 to 3 hours
  • Locate room temperature sensor behind front panel
  • Check sensor resistance at room temperature (should be 5 to 10 kilo-ohms)
  • If sensor reading is zero or infinite, replace the sensor

Error Code E3

Evaporator Coil Temperature Sensor Error

Symptoms: AC not cooling properly, error appears after running for some time.

Solutions:

  • Disconnect power to AC
  • Locate evaporator sensor clipped to evaporator coil
  • Check for visible damage or loose connections
  • Measure sensor resistance - replace if faulty
  • Check wiring back to PCB for continuity

Error Code E4

Outdoor Unit Error / Condenser Sensor Issue

Symptoms: AC runs but cooling is poor, outdoor unit very hot.

Solutions:

  • Clean outdoor condenser coil with water hose
  • Remove debris around outdoor unit
  • Check condenser temperature sensor connections
  • Measure sensor resistance (5 to 15 kilo-ohms depending on temperature)
  • Replace sensor if faulty

Error Code E5

Compressor Error / Overload Protection

Symptoms: Outdoor unit humming but compressor not starting, AC not cooling.

Solutions:

  • Turn off AC and let compressor cool for 30 to 60 minutes
  • Clean outdoor condenser coil thoroughly
  • Check compressor capacitor (common failure in Pakistani heat)
  • If capacitor is faulty, replace with exact microfarad rating
  • Ensure outdoor fan is running properly
  • If problem continues, call a professional technician

Warning: Compressor repair requires professional knowledge. Do not attempt DIY.

Error Code E6

Communication Error Between Indoor and Outdoor Units

Symptoms: AC turns on but no cooling, error appears after power fluctuation.

Solutions:

  • Turn off both units at circuit breaker for 15 minutes (complete reset)
  • Check all wiring connections between indoor and outdoor units
  • Look for rodent damage to communication cable (common in Pakistan)
  • Ensure connections are tight and corrosion-free
  • If wiring is good, one of the PCBs may need replacement

Error Code E7

Outdoor Fan Motor Error

Symptoms: Outdoor fan not spinning, compressor runs but AC not cooling.

Solutions:

  • Turn off power to outdoor unit
  • Remove debris or obstructions around fan
  • Check if fan rotates freely by hand
  • Inspect fan capacitor for bulging or leakage
  • Test capacitor with multimeter, replace if faulty
  • If capacitor is good, fan motor may need replacement

Error Code E8

EEPROM Error (Main Board Memory)

Symptoms: AC shows error immediately after power on, not responding to controls.

Solutions:

  • Try power reset - turn off circuit breaker for 15 minutes
  • If error persists, main PCB needs replacement
  • Contact Dawlance service center or certified technician
  • PCB must be exact match and properly programmed

Professional Only: PCB replacement requires technical expertise.

Error Code E9

High Pressure Protection

Symptoms: AC stops suddenly, shows error, restarts after cooling down.

Solutions:

  • Turn off AC and let pressure equalize (30 minutes)
  • Thoroughly clean outdoor condenser coil
  • Ensure outdoor fan is running properly
  • Remove any obstructions around outdoor unit
  • If problem continues, call technician for refrigerant check

Frequently Asked Questions

Why does my Dawlance AC show E1 error?
E1 indicates indoor unit communication or fan motor problem. Check if indoor fan is running. Clean fan and check connections. If fan is not running, capacitor or motor may need replacement.
How often should I service my Dawlance AC in Pakistan?
Service twice per year. Once before summer (February to March) and once before winter (October to November). In dusty cities like Karachi and Lahore, clean filters monthly and outdoor unit every 3 months.
What does E5 mean on Dawlance AC?
E5 indicates compressor error or overload protection. Let the unit cool for 30 to 60 minutes. Clean the outdoor unit and check if the outdoor fan runs. If the problem continues, call a technician.
Why is my Dawlance AC not cooling but running?
First check if any error code is displayed. If no code, clean the air filters and check the outdoor unit for dirt. Ensure the outdoor fan is running. If still not cooling, the refrigerant may be low. Call a technician.
How do I reset my Dawlance AC?
Turn off the AC from the remote. Then switch off the circuit breaker for 10 to 15 minutes. Turn the breaker back on, then turn on the AC. This clears temporary errors after power fluctuations.
Does Dawlance AC need a stabilizer in Pakistan?
Yes, especially in areas with frequent voltage fluctuations below 180 volts or above 250 volts. A stabilizer protects the PCB and compressor from damage.

Detailed Error Code Guide

Error Code CH01

Indoor Air Temperature Sensor Error

Meaning: The sensor that measures room temperature has failed.

Solutions: Turn off power. Locate sensor behind front panel near air intake. Check connections. Measure resistance at room temperature. Normal reading is 5 to 10 kilo-ohms at 25 degrees. Replace sensor if faulty.

Error Code CH02

Indoor Inlet Pipe Sensor Error

Solutions: Disconnect power. Locate inlet pipe sensor clipped to refrigerant pipe entering indoor coil. Check connections and measure resistance. Replace sensor if faulty.

Error Code CH03

Indoor Outlet Pipe Sensor Error

Solutions: Locate outlet pipe sensor on refrigerant pipe leaving indoor coil. Check connections and measure resistance. Replace sensor if faulty.

Error Code CH04

Outdoor Air Temperature Sensor Error

Solutions: Turn off power to outdoor unit. Locate outdoor air sensor behind grille near air intake. Check for visible damage or corrosion. Measure resistance. Replace sensor if faulty.

Error Code CH05

Outdoor Pipe Temperature Sensor Error

Solutions: Locate pipe sensor on outdoor condenser coil. Check connections which may be corroded from weather. Measure resistance. Replace if faulty.

Error Code CH06

Compressor Discharge Temperature Sensor Error

Solutions: Turn off AC and let compressor cool. Clean outdoor condenser coil. Locate discharge sensor on compressor discharge line. Check connections. Replace sensor if faulty. If error continues, refrigerant may be low. Call technician.

Error Code CH07

Outdoor Unit Communication Error

Solutions: Turn off both units at circuit breaker for 15 minutes. Check all wiring connections. Look for animal damage to communication cable. Ensure connections are tight. If wiring is good, one of the PCBs may need replacement. Install a voltage stabilizer for protection.

Error Code CH10

Compressor Drive Error

Meaning: Problem with the compressor drive circuit in inverter models.

Solutions: Check mains voltage. It should be 190 to 250 volts. If voltage is low, install a voltage stabilizer. Let the unit cool and reset. If the error continues, the inverter board or compressor may need professional diagnosis.

Professional Only: Inverter compressor issues require specialized diagnostic equipment.

Error Code CH14

Outdoor Fan Motor Error

Solutions: Turn off power to outdoor unit. Remove debris around fan. Check if fan rotates freely. Test fan capacitor with multimeter. Replace if faulty. If capacitor is good, the motor may need replacement.

Frequently Asked Questions

What does CH01 mean on LG AC?
CH01 indicates indoor air temperature sensor error. Check sensor connections and resistance. Replace if faulty. This is usually an easy DIY fix.
How do I reset my LG AC?
Turn off the AC from the remote. Then switch off the circuit breaker for 10 to 15 minutes. Turn the breaker back on, then turn on the AC. This clears temporary errors after power fluctuations.
Why does my LG AC show CH05?
CH05 is outdoor pipe sensor error. Check the sensor on the outdoor coil. It may be corroded from weather exposure. Replace if faulty.
Is LG AC good for Pakistan's voltage fluctuations?
LG inverter ACs have a wide voltage range of 170 to 260 volts. However, a stabilizer is still recommended for protection. Non inverter models definitely need a stabilizer.
How often should I service my LG AC?
Service twice per year. Once before summer in February or March, and once before winter in October or November. Clean filters monthly during summer. In dusty areas, clean the outdoor unit every 3 months.

Pakistan Specific Tips: LG inverter ACs have wide voltage range but a stabilizer is still recommended. Clean filters every 2 weeks in dusty areas. Check for animal damage to wiring, which is common in many areas. In extreme heat above 45 degrees, it is normal for ACs to run continuously. For professional service, use authorized LG service centers.

Safety Warning: Always disconnect power before any inspection. For compressor, refrigerant, or PCB issues, always call certified technicians. Inverter systems have high voltage DC that can be dangerous.
